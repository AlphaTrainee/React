# VS Code Extensions für den React-Kurs

Hier ist eine Zusammenfassung der empfohlenen Erweiterungen für eine effiziente React-Entwicklung.

## 1. Snippets & Autocomplete
| Extension | Beschreibung | Wichtige Kürzel |
| :--- | :--- | :--- |
| **ES7+ React/Redux/React-Native snippets** | Die wichtigste Sammlung für React-Entwickler. | `rfce`, `rafce`, `useState`, `clg` |

## 2. Code-Qualität & Formatierung
| Extension | Zweck | Hinweis |
| :--- | :--- | :--- |
| **Prettier - Code formatter** | Automatische Formatierung (Einrückung, Semikolons). | Publisher: **Prettier** (esbenp.prettier-vscode) |
| **ESLint** | Findet Fehler und erzwingt Coding-Standards. | Unverzichtbar für sauberen Code. |
| **Error Lens** | Zeigt Fehlermeldungen direkt neben dem Code an. | Hilft, Fehler sofort zu verstehen. |

## 3. Hilfreiche Utility-Tools
| Extension | Funktion |
| :--- | :--- |
| **Auto Rename Tag** | Ändert das schließende HTML/JSX-Tag automatisch mit. |
| **Tailwind CSS IntelliSense** | Autocomplete für CSS-Klassen (falls Tailwind genutzt wird). |
| **Pretty TypeScript Errors** | Macht komplexe TypeScript-Fehler lesbar. |

---

## Konfiguration für Prettier
Damit Prettier optimal funktioniert, sollten folgende Einstellungen in VS Code (`Strg + ,` bzw. `Cmd + ,`) aktiv sein:
1. **Editor: Format On Save**: Aktivieren (Haken setzen).
2. **Editor: Default Formatter**: Auf `Prettier - Code formatter` stellen.
