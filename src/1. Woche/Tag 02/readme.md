# React Kurs: Woche 1 / Tag 2

- [React Developer Tools](https://react.dev/learn/react-developer-tools)

**Installation**

```bash
npm create vite@latest
npm i --save-dev prettier
npm i -D eslint-config-prettier
```

danach in den Projekt Ordner
**Server starten**

```bash
npm run dev
```

**Production Build**

```bash
npm run build
```

- code wird optimiert
- der code wird transpiliert
- code wird minifiziert
- es entsteht der Ordner `dist`
  - dies ist das Bundle, welches verteilt werden kann
